## Projekte

### Medivo – eigenes Konzept, in Entwicklung

WebApp für Menschen mit chronischen Erkrankungen: Symptome, Medikamente und Termine im Alltag dokumentieren und daraus eine druckbare Zusammenfassung fürs Arztgespräch erstellen. Vorlagen für häufige Erkrankungen und sieben Darstellungsmodi (z. B. Senioren, Minimal, Autismus) passen die Oberfläche an unterschiedliche Bedürfnisse an.

React · TypeScript · Vite  
[Projektseite](https://paulina-codes.github.io/portfolio/tracker.html) · [Live-Demo](https://paulina-codes.github.io/portfolio/medivo-demo/) · [Quellcode](https://github.com/paulina-codes/medivo)

### Pandemie-Datenbank – Bachelorarbeit, Note 1,3

Konzept einer Manöverstudie, mit der Entscheider im Gesundheitswesen Pandemiesituationen durchspielen können. Grundlage ist eine relationale Datenbank, in der reale COVID-19-Berichte (bis 31.12.2021) nach Quelle, Kategorie, Pandemiephase und Entscheidungsrelevanz strukturiert sind.

PostgreSQL · SQL · Datenmodellierung  
[Projektseite](https://paulina-codes.github.io/portfolio/bachelorarbeit.html)

### Mediplan – Studienprojekt

Webanwendung zur Verwaltung von Ärzten, Patienten und verschreibungspflichtigen Rezepten, mit getrennten Ansichten für Administration, Ärzte und Patienten und unter Beachtung von Datenschutzanforderungen für Gesundheitsdaten.

[Projektseite](https://paulina-codes.github.io/portfolio/mediplan.html)

## Über diese Website

- Statisches HTML, CSS und JavaScript, ohne Framework und ohne Build-Schritt
- Responsiv für Desktop und Smartphone, Screenshots per Klick vergrößerbar
- Die Medivo-Demo liegt als fertig gebaute React-App im Ordner `medivo-demo/`, der Quellcode im eigenen [Medivo-Repository](https://github.com/paulina-codes/medivo)

```
├── index.html           Weiterleitung auf portfolio.html
├── portfolio.html       Startseite
├── mediplan.html        Projektseite Mediplan
├── bachelorarbeit.html  Projektseite Bachelorarbeit
├── tracker.html         Projektseite Medivo
├── medivo-demo/         Interaktive Medivo-Demo (Build)
└── assets/              Logo und Screenshots
```

Lokal ansehen: Repository klonen und `portfolio.html` im Browser öffnen.
